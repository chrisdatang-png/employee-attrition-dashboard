# Employee Attrition Dashboard

## Project Overview
This project analyzes employee attrition using Power BI. The dashboard provides insights into employee turnover across departments, age groups, salary levels, and overtime status.

## Tools Used
- Power BI
- Excel

## Key Insights
- Total employees: 1,416
- Employees who left: 229
- Overall attrition rate: 16.17%
- R&D had the highest number of employees who left.
- Employees working overtime had a higher attrition rate than those who did not.
- The 18–25 age group had the highest attrition rate.
